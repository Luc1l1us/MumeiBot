A Discord Bot that utilizes an old version of ChatGPT and the Canvas LMS API for students.

## Commands

- help
  - prints out the bot's registered commands
- assign
  - gets the assigned courses and details from the user's inputted CanvasAPI Token and prints it out for the user to see
- time
  - prints out the current time
- date
  - prints out the current date
- whoami
  - gets the user's name and prints it out

## Tree commands

- chatgpt
  - utilizes discord's tree functionality to ask the user to provide a question for ChatGPT to answer
